Purpose

Black missing persons cases often receive uneven public attention. This project brings case records, location information, investigation details, and active sources together for research, public awareness, and continued visibility.

The database does not accept tips, conduct investigations, or determine guilt. Anyone with case information should contact the investigating agency listed on the relevant profile.

Approach

data/cases.csv is the project’s main source file. Automated checks use it to rebuild the case documents, maps, statistics, and web pages, keeping every public format consistent.
